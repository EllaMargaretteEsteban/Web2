# E-Load Tracker App

A web application built using the **MVC (Model-View-Controller)** architectural pattern for tracking and managing e-load transactions.

## 👥 Group Members & Contributions
* **John Rey M. Capote** - Project Setup, Wallet UI Components & Quick-sell Integration
* **Crisel Joy** - System Proposals, Workflow Coordination & Walkthrough Presentations
* **Ella Margarette** - User Interface Views, Component Layouts & Repository Management

## 🚀 Features
* **Wallet Top-up:** Add balance using quick-amount chips or a custom input.
* **Transaction History:** View recent transactions and history logs.
* **Responsive Layout:** Optimized for both desktop and mobile screens.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6 Modules)
* **Architecture:** MVC (Model-View-Controller)
